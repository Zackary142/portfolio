VoQuota: quoting, invoicing and payments for tradespeople

Co-founder · Live

Tradespeople lose jobs when quoting takes too long, and writing quotes in Word after a day on site takes hours. VoQuota lets them build a quote on their phone in a few minutes, send it, turn it into an invoice with one click once the customer accepts, and get paid by card. I co-founded it with a fellow software engineering intern from Virgin Media O2, and we designed, built and launched it between the two of us.

  • Quote builder that totals labour, materials and extras, with VAT
  • Customer page to accept or decline, with no account needed
  • Card payments on every invoice
  • Each business's own branding on every quote, invoice and PDF

Job Application Tracker

Solo project · Live

A serverless app on AWS with sign-in, built and deployed entirely as code. I built it to keep track of my own job applications. The app is deliberately basic; the part I cared about was how it's built and shipped. The infrastructure is all Terraform, every change goes through a CI/CD pipeline, and there are no AWS keys stored anywhere.

How it's built
  • A FastAPI app on one arm64 Lambda behind API Gateway, with DynamoDB for storage, so it costs pennies a month and nothing while idle
  • Sign-in through Cognito, with API Gateway checking the token before any code runs, and every record keyed by the user id from that verified token
  • The frontend sits in a private S3 bucket served through CloudFront, and the bucket is never public
  • Terraform split into two stacks, with remote state in a versioned S3 bucket and native locking
  • GitHub Actions signs in to AWS with OIDC, plans on every pull request, then applies, deploys and smoke tests on merge, including a check that the API rejects requests without a token
  • Least-privilege IAM throughout, with unit tests run against a mocked DynamoDB
